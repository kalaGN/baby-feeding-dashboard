# 设置面板与 CSV 备份还原

## 已确认范围
按用户确认的设计实现公共设置 UI：备份与还原、检查更新、关于（最后）。
备份为手动导出 CSV；还原支持 CSV 和现有安卓服务器还原。服务地址置于服务器还原内部。
安卓、Web、iOS 共用 HTML/CSS/ES5 JavaScript；系统文件操作由原生桥接处理。

## 数据契约与验收
- UTF-8 BOM CSV，列为记录编号、日期、时间、奶量(ml)、自动记录、时间戳(ms)。时间戳是还原的准确依据，日期时间便于查看。
- 包含全部历史记录，保持编号、毫秒时间、奶量、自动标记；Excel 公式前缀转义。
- 最大 1 MB / 10000 条，拒绝非法字段、重复编号、非整数或越界奶量（兼容旧记录 1–2000 ml）；损坏文件不部分导入。
- 先预览条数及日期范围，确认后覆盖；取消、解析失败、写入失败、版本冲突均保留原记录。
- CSV 仅备份记录。还原沿用当前间隔，并重置无历史时的计时起点。
- 安卓 SAF 创建/选择文件；iPad UIDocumentPicker；Web Blob 下载与文件选择。原生文件回调仅传数据，由公共解析器校验。
- 检查更新沿用安卓现有流程；Web/iOS 明确显示平台支持状态。关于为公共面板。

## 计划与任务
1. CSV 编解码模块和边界测试。
2. 公共设置面板、预览确认、以 revision 校验写入，失败不更改页面状态。
3. 安卓/iOS 文件桥接；安卓服务器读取交由公共面板预览确认。
4. 文档、离线资源版本、APK 更新；测试与构建、隔离浏览器验证。

## 命令与文件
`node --test tests/*.test.mjs`；`android/gradlew -p android :app:testReleaseUnitTest :app:assembleRelease :app:lintRelease`。
共享代码 `dist/backup.js` / `dist/settings.js` / `dist/app.js`，测试 `tests/`；原生工程 `android/` / `ios/`。
采用现有 ES5 函数与回调风格；无新增运行依赖。真实数据、签名文件、用户编辑器配置不提交；发布另由用户指令授权。
