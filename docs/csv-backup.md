# CSV 备份与还原

设置面板与看板共用 UI，支持日夜模式及手机横屏滚动。主页只有“备份与还原”“检查更新”“关于”。

## 导出

选择“导出 CSV”，导出所有日期的喝奶记录。Android 使用系统文件保存器；iPad 保存到“文件”；Web 下载到浏览器下载目录。选择取消不会修改记录。不自动上传或备份到服务器。

UTF-8 BOM / CRLF 编码，列：记录编号、日期、时间、奶量(ml)、自动记录、时间戳(ms)。日期时间按导出设备本地时区显示，毫秒时间戳是还原依据。自动标记使用“是/否”，保留旧记录 1–2000 ml（新增记录仍为10–300 ml）。记录编号中的引号、逗号、换行按CSV转义；公式前缀添加单引号避免表格软件执行，还原时去除该保护字符。

## CSV 还原

1. 选择本应用导出的 CSV（最大1 MB、10000条）。
2. 校验表头、字段、编号唯一性、时间和奶量；不跳过坏行。
3. 展示备份记录条数、日期范围，以及当前将被替换的条数。
4. 点击“确认还原”后替换全部历史记录。空备份将清空记录，也会明确提示。

请先导出当前记录；还原为替换，不合并。取消、文件不合法、写入失败不会覆盖原记录；预览后记录版本变化则拒绝本次还原，须重新预览。CSV 不包含间隔与主题设置；沿用当前间隔，还原时更新无历史记录的计时起点。间隔及全量状态可另用服务器的 `state.json` 备份。

## 从服务器还原（Android）

在此入口配置服务地址，输入 `http://电脑IP:4173` 并点击“读取记录”。读取成功后同样预览再确认，服务器间隔随服务器记录一起还原。服务地址记住上次选择，日常离线使用不连接服务器。服务器原数据保持不变。

## 更新与关于

安卓沿用每天最多一次的自动检查，手动检查通过公共面板调用原生更新器。Web 刷新更新；iPad 工程通过 Xcode 重新构建安装。关于显示应用介绍、版本和 MIT 项目信息。
