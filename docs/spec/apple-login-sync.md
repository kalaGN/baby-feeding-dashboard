# 可选 Apple 登录与跨平台同步（需求已确认）

## 目标与确认范围

2026-10-13 用户确认本需求：iPad、Android、Web 使用同一 Apple 账号同步；有阿里云空服务器。具体部署地址、操作系统和域名尚待提供。现有免登录、本机记录功能保留。

## 产品行为

- 设置增加“账号与同步”，提供通过 Apple 登录入口。未登录不限制新增、编辑、删除、统计和 CSV 功能。
- iPad 使用原生 Apple 授权；Android 和 Web 使用 Apple 网页授权。同一开发者团队下配置 App ID / Services ID，服务端验证身份；不可把电子邮箱当作账号主键。
- 首次登录先读取云端，展示本机和云端记录数量。用户确认后才合并上传本机旧记录；可选择仅使用云端，原本机记录先留作独立本地数据，不静默删除。
- 同步喂奶记录（含自动标记）及喂奶间隔。夜间模式、屏幕展示设置仅保存在各设备。
- 离线修改先写本地待同步队列，恢复联网后重试；显示“已同步 / 待同步 / 同步失败”及最后成功时间，允许手动重试。
- 同一记录并发修改不按设备时钟静默覆盖：基于服务端版本检测冲突，展示冲突并选择保留内容。删除使用删除标记，避免离线旧设备把记录复活。
- 自动记录按账号和预定时段幂等；联网时由服务端去重，离线时保留待同步计划记录，避免多设备重复累计。
- 登录账号的数据和访客数据隔离。退出后保留该账号的本机缓存且不可在其他账号下上传；返回独立访客数据。切换账号先处理未同步变更。
- 提供“删除账号及云端数据”，再次确认后删除云端记录并撤销 Apple 授权，明确各设备离线缓存处理；重新上线时不得重建已删除账号数据。

## 技术方案

- 新建独立 HTTPS 同步服务，按用户隔离数据，使用 SQLite 事务持久化（首版单实例），部署前确认容量与备份路径。
- 当前 `server.mjs` 的局域网共享单份 `state.json` 不能直接公开作为多用户云服务，继续用于原局域网模式。
- Apple 身份令牌在服务器验证签名、issuer、audience、expiry、nonce；网页流程验证 state，authorization code 单次交换。密钥只放服务器。
- 应用会话使用可撤销令牌；iPad/Android 存入 Keychain/Keystore；Web 使用 Secure、HttpOnly Cookie，并验证 CSRF。刷新令牌加密存储以支持 Apple 授权撤销。
- 每条记录增加服务端版本、变更序号和删除状态。增量拉取使用游标，上传使用幂等请求 ID 和预期版本。
- 账号资料只请求必要范围；不要求宝宝姓名。不把授权令牌、记录正文或私密信息写进日志。
- Apple App ID 和网页 Services ID 归组需在会员开通后配置并用实际授权验证跨端身份一致性。

## 项目位置与风格

- `dist/`：共用账号设置与同步状态界面，维持 ES5 兼容。
- `ios/BabyFeedingDashboard/`：原生授权、Keychain、联网桥接与本地队列。
- `android/app/src/`：浏览器授权回调、Keystore 与本地队列。
- `sync-server/`：独立账号、同步服务和迁移；`tests/` 及对应原生测试目录验证。
- 沿用明确函数和现有验证方式，例如 `if (!validEntry(entry)) return ...`；不在原局域网存储逻辑中混入云端用户身份。

## 验证与命令

- 现有回归：`node --test tests/*.test.mjs`。
- iPad 构建：`xcodebuild -project ios/BabyFeedingDashboard.xcodeproj -scheme BabyFeedingDashboard -sdk iphonesimulator -configuration Debug -derivedDataPath ios/build CODE_SIGNING_ALLOWED=NO build`。
- 新服务测试覆盖认证失败、用户隔离、幂等、版本冲突、删除传播、账号注销与事务失败；服务技术栈和依赖经方案审核确定后补充精确运行命令。
- 原生和浏览器验证：三个平台同账号互通；两账号完全隔离；断网修改重连不丢数据；旧记录未经确认不上传；注销后旧设备无法重新上传。
- Apple 测试必须用真实账号与配置；模拟令牌测试不能证明实际 Apple 登录或线上同步可用。

## 边界与前置条件

- 需求已由用户确认。按 spec-driven-development 技能，下一步审核实现计划与任务，再编码。
- 不上传已有真实记录，不将服务器直接暴露为无认证接口，不提交密钥，不覆盖旧本机数据。
- 涉及新增数据库、依赖和正式部署，在具体计划中列出并审核；新增云端功能需同步更新隐私政策及商店数据收集申报。
