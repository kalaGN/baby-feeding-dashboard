# 更新网络重试

已确认：检查发布信息与下载 APK 遇到网络异常时，最多自动重试两次，等待 2 秒、5 秒（初次加重试共三次）。
重试涵盖连接失败、超时、断流及 HTTP 408/429/500/502/503/504。HTTP永久错误、TLS证书、发布格式、文件写入、哈希/包名/签名校验错误不自动重试。
每次下载重试从头写临时文件，完整下载后才执行安装包校验；取消或关闭应用停止重试并清理临时文件。
手动检查/下载网络重试耗尽后，前台显示“重试/稍后”；自动检查失败保持安静，仍计入当天检查额度，内部重试属于同一轮。

实现：纯 Java `UpdateRetry` 控制次数/等待/取消，`AppUpdater` 接入实际连接和界面。
验证：注入假时钟与网络操作，覆盖延迟、成功、耗尽、永久错误、取消；执行 `:app:testReleaseUnitTest :app:assembleRelease :app:lintRelease` 并核对发布签名。

验证结果：16项 Android 单元测试通过（含7项网络重试测试）；Release构建、Lint及签名检查通过。未做实机断网验证。
