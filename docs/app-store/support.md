# 喝奶看板技术支持

喝奶看板用于成年家长和照护者在 iPad 上查看喂奶时间、记录奶量及查看统计。

## 使用方法

- 首次启动默认间隔为 3 小时；没有记录时提示添加第一条记录。
- 点击加号新增记录；默认奶量 120 ml，通过上下滚动选择。
- 点击记录编辑，垃圾桶图标删除记录。
- 点击当前间隔分别调整小时与分钟。
- 点击统计图标查看近 7 天、30 天的奶量与平均奶量。
- 点击标题旁的齿轮进入 CSV 备份与还原；还原需要预览并确认。
- 点击月亮切换夜间模式。

## 常见问题

### 自动记录是否代表实际已喂奶？

不是。自动记录是应用在前台按计划添加的记录，请照护者核实，必要时修改或删除。后台或关闭期间不补记。本应用不提供医学建议。

### 换设备如何保留记录？

在旧设备导出 CSV，再在新设备选择 CSV，预览并确认还原。卸载前请备份；数据仅保存在当前设备中，不提供开发者服务器同步。

### 备份文件是否上传给开发者？

不会。文件保存位置由你在系统文件选择器中选择；选择云盘时由相应云盘服务处理。

### 如何反馈问题？

到 [GitHub Issues](https://github.com/kalaGN/baby-feeding-dashboard/issues) 提交问题，注明 iPad 型号、iPadOS 版本、应用版本和操作步骤。截图请遮挡私人数据，不要上传真实 CSV 记录或儿童身份信息。
