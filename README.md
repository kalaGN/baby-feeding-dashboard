# Baby Feeding Dashboard · 喝奶看板

为平板横屏桌面设计的喝奶记录看板。大字号展示当前时间、上次与下次喝奶时间，支持记录管理、自动记录和夜间模式。

采用原生 HTML、CSS、JavaScript 和 Node.js，无第三方运行依赖。网页版记录保存在运行服务的电脑上，平板浏览器保留同步副本；Android 独立版记录保存在平板。

## 功能

- **时间看板**：当前时间、上次喝奶时间与奶量、下次喝奶的具体钟点。
- **记录管理**：新增、编辑、删除记录，统计今日奶量和次数。
- **自定义间隔**：支持 0.1 小时精度，到预计钟点自动记录。
- **服务器保存**：自动迁移旧浏览器记录，保存到本地文件，支持备份与恢复。
- **平板体验**：横屏布局、大字号、夜间模式与全屏，兼容 MI PAD 4 使用场景。

## Android 安装版

提供 Android 独立安装版，支持 Android 6.0 及以上版本。页面内置于 APK，记录保存在平板，手机和平板默认横屏，全屏并保持屏幕常亮；手机横屏使用紧凑布局，弹窗可滚动；日常使用无需电脑服务或网络。支持导出 CSV 备份、预览后从 CSV 还原，以及读取服务器记录后确认还原。

从 [GitHub Releases](https://github.com/kalaGN/baby-feeding-dashboard/releases/latest) 下载 APK。安装、旧记录迁移及 APK 构建步骤见 [Android 安装版说明](android/README.md)。

## 快速开始

### 环境要求

- Node.js 22，已在该版本验证。
- 运行服务的电脑和平板连接同一个局域网。

### 下载与启动

```bash
git clone https://github.com/kalaGN/baby-feeding-dashboard.git
cd baby-feeding-dashboard
node server.mjs
```

无需安装依赖或执行构建。启动后：

1. 在电脑浏览器打开 `http://localhost:4173`。
2. 查看电脑的局域网 IP。macOS 可在“系统设置 → Wi-Fi”中查看。
3. 在平板浏览器打开 `http://<电脑的局域网 IP>:4173`，横屏使用。

电脑需保持开机并运行服务。首次迁移旧记录时，请先用原来有记录的平板浏览器打开页面。

### 配置

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `PORT` | `4173` | 服务监听端口 |
| `MILK_BOARD_DATA_DIR` | 项目下的 `data/` | 数据文件保存目录 |

macOS / Linux 示例：

```bash
PORT=8080 MILK_BOARD_DATA_DIR=/path/to/milk-board-data node server.mjs
```

## 使用说明

### 记录喝奶

- **新增**：点击“记录喝奶”，通过下拉框分别选择月、日、小时和分钟后保存（不会弹出圆形时钟轮盘）。奶量默认 **120 ml**，通过上下滚动选择 **10–300 ml**，每档 **10 ml**，无需选择年份。
- **编辑**：点击“今日记录”中的一条记录，修改时间或奶量。
- **删除**：点击记录右侧的 **×**，确认后删除。

新增记录按当前年份保存；一月选择十二月时，按上一年保存。编辑记录时保留原年份。

### 设置间隔与自动记录

- 点击“当前间隔”设置两次喝奶的间隔，支持 **0.1 小时**精度，例如 **3.1 小时 = 3 小时 6 分钟**。
- 页面打开且到达预计钟点时，会自动添加一条标有“自动”的记录，奶量沿用上一笔。
- 没有历史记录时，从设置间隔的时间开始计时，第一笔默认 **120 ml**。
- 自动记录可以编辑或删除；页面关闭期间错过的时段不会补记。

### 奶量统计

点击今日喝奶区域右上角的统计图标，查看近7天或近30天每日奶量柱状图、总奶量和日均奶量。统计包含今天，没有记录的日期按0计算，日均按完整7天或30天计算并四舍五入到整数ml；30天图表可横向滑动。

### 夜间模式与全屏

- 点击右上角的月亮按钮切换夜间模式，页面会记住选择。
- 点击旁边的全屏按钮进入或退出全屏。
- 平板若仍自动熄屏，请在系统的显示设置中调整休眠时间。

## 数据管理

### 保存与迁移

首次打开新版页面时，如果服务器还没有数据，平板会将该浏览器中的旧记录和间隔导入服务器。之后每次修改先暂存在平板，再同步写入服务器的 `state.json`。

服务器已有数据时，页面读取服务器记录；未同步的本机修改会重试保存。若两边记录发生冲突，页面会提示并保留本机副本，避免直接覆盖。清理浏览器数据前，请确认页面没有同步失败提示。

默认数据文件为 `data/state.json`，该目录已被 Git 忽略，不会随代码提交到 GitHub。

### CSV 备份与还原

点击“喝奶看板”右侧齿轮 → **备份与还原**：导出全部历史记录为 UTF-8 CSV 文件；从 CSV 还原时先展示条数、日期范围和覆盖提示，确认后替换全部记录。取消或文件校验失败不会改动记录。CSV 保留记录编号、日期、时间、奶量、自动标记及准确时间戳，不包含间隔或夜间模式设置。

CSV 还原支持本应用导出的文件，限制 1 MB、10000 条记录；请勿手动修改备份。Android 使用系统文件保存/选择器，iPad 使用“文件”，Web 使用浏览器下载/选择文件。Android 的“从服务器还原”内配置服务地址，读取后确认还原。[详细说明](docs/csv-backup.md)。

### 服务器文件备份与恢复

1. 备份：停止服务后，复制 `data/state.json` 到其他位置保存。
2. 恢复：停止服务，用备份替换数据目录中的 `state.json`，然后重新启动服务。

更换电脑或部署位置时，请一并迁移数据目录。

## 部署与使用边界

- 服务默认监听 `0.0.0.0`，供同一局域网中的设备访问。
- 当前没有登录验证，同一局域网内知道地址的人可以读取或修改记录，请在可信任的局域网使用。
- 自动记录由打开的页面触发；服务需要运行，平板页面也需要保持打开。
- 普通局域网 HTTP 地址无法保证安装为桌面应用或离线缓存。
- 部署时需要运行 `server.mjs`。仅上传 `dist/` 到静态网站无法使用服务器保存功能。

## 开发与验证

修改 `dist/` 中的文件即可，无需构建。更新前端资源时，同步调整 `index.html` 与 `sw.js` 中的缓存版本。

```bash
node --check dist/app.js
node --check dist/sw.js
node --check server.mjs
node --test tests/*.test.mjs
```

测试覆盖自动记录、日期与间隔输入、旧记录迁移、冲突保护和服务重启后的数据恢复。
