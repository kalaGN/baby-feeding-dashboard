# 喝奶看板

为平板横屏桌面设计的喝奶记录看板。显示当前时间、上次喝奶、下次喝奶的具体钟点、今日累计和今日记录。记录保存在运行服务的电脑上，平板浏览器保留一份同步副本。

## 在平板上打开

1. Mac 和平板连接同一个 Wi-Fi。
2. 在本目录运行 `node server.mjs`。
3. 在 Mac 的“系统设置 → Wi-Fi”查看局域网 IP。
4. 在平板浏览器输入 `http://<Mac 的局域网 IP>:4173`，横屏使用。Mac 需保持开机并运行服务。

点击“记录喝奶”选择月、日和时分并填写奶量，无需选年份；点击今日记录可修改已有记录，记录右侧的 × 可删除。新增记录默认按今年保存，一月选择十二月时按上一年保存；编辑记录会保留原年份。间隔支持 0.1 小时精度，例如 3.1 小时等于 3 小时 6 分钟。设置间隔后，到预计钟点会自动添加一条标有“自动”的记录，奶量沿用上一笔；没有历史记录时，从设置间隔的时间开始计时，第一笔按 120 ml 记录。页面关闭期间错过的时段不会补记。右上角月亮按钮切换夜间模式，并记住选择；旁边的按钮切换全屏。MI PAD 4 若仍自动熄屏，请在平板系统的显示设置中调整休眠时间。

## 数据保存与迁移

首次打开新版页面时，如果服务器还没有数据，平板会把原来保存在该浏览器中的记录和间隔导入服务器。之后每次修改先暂存在平板，再同步写入本目录的 `data/state.json`；文件不会提交到 GitHub。服务器已有数据时，以服务器为准，避免旧浏览器副本覆盖记录。页面会在连接或同步失败时提示，未同步的本机记录会在连接恢复后重试。清理浏览器数据前，请确认页面没有同步失败提示。

Mac 必须保持开机并运行 `node server.mjs`，平板才能读取或保存记录。定期备份 `data/state.json`；需要恢复时先停止服务，再用备份文件替换它。请只在可信任的局域网使用，目前同一局域网内知道看板地址的人可以读取或修改记录。

普通局域网 HTTP 地址无法保证“添加到桌面”及离线缓存。仅把 `dist/` 放到静态网站无法使用服务器保存功能；部署到其他电脑时也需要运行 `server.mjs` 并保留 `data/`。
