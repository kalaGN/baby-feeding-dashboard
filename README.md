# 喝奶看板

为小米 MI PAD 4 横屏桌面设计的喝奶记录看板。显示当前时间、上次喝奶、下次喝奶的具体钟点、今日累计和今日记录。数据只保存在打开页面的那台设备浏览器中。

## 在平板上打开

1. Mac 和平板连接同一个 Wi-Fi。
2. 在本目录运行 `node server.mjs`。
3. 在 Mac 的“系统设置 → Wi-Fi”查看局域网 IP。
4. 在平板浏览器输入 `http://<Mac 的局域网 IP>:4173`，横屏使用。Mac 需保持开机并运行服务。

点击“记录喝奶”选择月、日和时分并填写奶量，无需选年份；点击今日记录可修改已有记录，记录右侧的 × 可删除。新增记录默认按今年保存，一月选择十二月时按上一年保存；编辑记录会保留原年份。间隔支持 0.1 小时精度，例如 3.1 小时等于 3 小时 6 分钟。设置间隔后，到预计钟点会自动添加一条标有“自动”的记录，奶量沿用上一笔；没有历史记录时，从设置间隔的时间开始计时，第一笔按 120 ml 记录。页面关闭期间错过的时段不会补记。右上角月亮按钮切换夜间模式，并记住选择；旁边的按钮切换全屏。MI PAD 4 若仍自动熄屏，请在平板系统的显示设置中调整休眠时间。

普通局域网 HTTP 地址无法保证“添加到桌面”及离线缓存。将 `dist/` 放到 HTTPS 网站后，浏览器支持时可安装为桌面应用并缓存页面。记录仍只在平板浏览器本地，不会上传。清理浏览器数据会清除记录。
